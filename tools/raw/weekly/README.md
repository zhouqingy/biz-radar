# 每周增量数据目录

定时任务每轮把新检索到的项目写入本目录，文件名建议 `YYYY-MM-DD.json`（如 `2026-10-06.json`）。
`update_weekly.py` 会扫描本目录下所有 `.json` 并合并进主库（自动去重、分类、分级）。

## 每条记录的字段（与 raw/jiangsu.json 等省级文件完全一致）

```json
{
  "t": "项目标题（必填）",
  "rg": "江苏|浙江|安徽|上海（可省略，会按标题/摘要里的城市名自动推断，推断不出则丢弃）",
  "city": "城市（可省略）",
  "st": "招标公告|招标计划|中标候选人公示|中标结果公示|立项公示|变更公告|其他",
  "buyer": "业主单位",
  "win": "中标单位（未出结果留空）",
  "amt": 445840000,                 // 金额，单位「元」；不确定填 null
  "amtTxt": "中标价格445840000.00元", // 金额原文（可省略）
  "d": "2026-07-28",                 // 公告日期
  "dl": "2026-08-20",                // 投标截止（可省略/填 null）
  "p": "来源平台名称",
  "url": "公告原文链接",
  "snip": "摘要：机组规模、锅炉容量、工艺路线等关键信息",
  "mode": "EPC|施工总承包|EP|...",
  "biz": "（可省略，由分类引擎自动判定）",
  "sub": "（可省略，自动判定）"
}
```

## 采集渠道（参考）
- 四地公共资源交易中心 / 招标投标公共服务平台
- 投资项目在线审批监管平台（立项公示）
- 重点客户企业采购平台（宝华、皖能、浙能、中天、南钢…）
- 行业媒体（北极星电力网、环保在线、化工报等）

## 采集重点（贴合公司主业）
1. 能源清洁高效利用：燃煤火电、煤气发电、余热发电、热电联产、光伏+储能
2. 废水处理（海水淡化、冶金废水零排放）、废气处理（脱硫脱硝）、环境修复
3. 目标客户：钢铁 + 有色金属企业，少部分化工、水泥制造业
4. 排除：纯监理/检修/备件/运维、纯蒸汽管网施工
