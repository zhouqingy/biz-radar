二、优先级 A / B / C / D 怎么定

      
    
        
  • 由「业务匹配度 + 项目规模 + 所处阶段 + 是否总承包标的」四项加权得出综合分
    • 
        
  • A 战略必争：能源主业 + 综合分≥78 + 有明确规模证据（≥1亿元 / ≥30MW / ≥220t/h），且为总承包标的
    • 
        
  • B 重点跟进：能源主业中大型，或非能源主业的大额相关项目
    • 
        
  • C 可关注：主业中小额、或立项早期线索
    • 
        
  • D 暂不跟进：非主业、零散标段、监理/运维/纯设备采购类
    • 
        
  • 注意：标题含「监理、检修、备件、询价、谈判采购」等非总承包表述的会降权，因为公司做 EPC/F+EPC/EPC+O/EP
    • 
        
  • 纯供热/蒸汽管网施工（无发电设备内容）不作为目标标的：商机库中降级为 C 并单列「供热管网施工」子类，且不计入中标情报的对手榜
    •

二·二、附件清单与原始发布平台（2026-10-21 新增）

      
    
        
  • 附件清单：卡片底部出现「📎 附件 N 个」时，点开可看到该公告挂的所有附件（招标文件、工程量清单、图纸、资格审查条件等），能直接下的给直接下载链接，没抓到直链的标注「需到原文页下」。附件里往往是信息量最大的部分——控制价、评标办法、业绩门槛都在里面，建议先看附件再判断要不要跟。
    • 
        
  • 原始发布平台：省级交易平台很多只是「转发」市级或行业平台的公告，附件也常挂在下级平台。卡片上的「原始发布 · XX平台」就是从公告详情页里读出来的真正首发地（例如「浙江能源集团智慧供应链一体化平台」「乐采云平台」「南京云平台」）。有直达链接的直接点，只有平台名的给一个按标题搜索的入口。
    • 
        
  • 两种风险标记：标「转载源」的说明这条来自聚合站（如招标网、中国采招网），不是交易平台原文，链接会失效；标「原文可能打不开」的是抓取时发现详情页是空壳（白页），可改用搜索入口找。
    • 
        
  • 已知覆盖范围：附件扫描是逐条打开详情页做的，浙江、江苏两站结构规整，覆盖率最高；部分市直平台公告正文里压根不挂附件（公告本身就是全部内容），这类不会有附件，属正常。
    •

三·二、投标文件拿不到（结论已确认，不必再试）

      
    
        
  • 《招标投标法实施条例》只要求公示中标候选人、中标价、评标结果。投标文件正文不公开——只有招标人、行政监督部门、评标委员会能看。
    • 
        
  • 所以任何公开渠道（含政府采购网、公共资源交易中心）都没有投标文件下载入口，企查查也没有。网上流传的「投标文件下载」多是投标人自己上传的模板或已过期的样例。
    • 
        
  • 替代路径：①公告详情页（本库已直链，含联系人/电话/中标价）②中标结果公示里的「中标单位 + 报价 + 工期 + 项目负责人」③向招标人或代理机构索取（公开招标的中标结果属可查询信息）④第三方中标业绩库（如剑鱼标讯、千里马，需付费）。
    • 
      

      
三·补、提前量信号（正式招标之前，最值得盯的一类）

      
    
        
  • 卡片上带 提前量 · XXX 绿色徽标的，说明这条还没到正式招标，来源有七类：
          
    · 发改委核准 / 备案批复——业主刚拿到批文，通常比招标早 3-6 个月
          
    · 招标计划（预公告 / 采购意向）——业主已报计划，通常早 1-3 个月
          
    · 环评公示——项目在环评阶段就暴露，通常早 2-4 个月，且摘要里常有机组规模与工艺路线
          
    · 技改备案（工信/经信部门）——客户群做节能技改、余热发电、超低排放改造都要先备案，命中率最高的一类
          
    · 重大项目清单——省/市/县年度重点建设项目计划，一年 1-2 次，一次几百条
          
    · 上市公告（巨潮资讯）——上市公司募投与对外投资，董事会阶段就披露，有业主有金额，质量最高但密度最低（一年个位数）
          
    · 热电规划（省市发改委对《热电联产规划 / 集中供热规划》的批复）——最早的一类，比核准还早 1-3 年。批复正文会直接点名未来要新建的热源点（例："原则同意…新建丰县经济开发区热电联产项目作为区域主力热源点"），区域热源点布局就此定盘，适合提前跑关系、跟进度
        
    • 
        
  • 用途：这类项目现在就能接触业主、做技术方案与联合体铺垫，等它挂到交易中心再动手就来不及了。商机库顶部泳道点「立项早期·拟招标」可单独筛选
    • 
        
  • 注意：提前量条目往往没有金额与截止时间，综合分会被低估，不要因为分数低就忽略——重点看业主是谁、规模多大
    •

八、A/B 级项目「单位自动挖掘」

      
    
        
  • 每周更新时，脚本会扫描商机库里全部 A 级（战略必争）+ B 级（重点跟进）项目的中标记录，自动提取中标单位与联合体成员，卡片上带 「库内挖掘 · N 次 / X 亿」 标签的就是机器挖出来的
    • 
        
  • 分流规则：能独立牵头 EPC 的电力/能源/环保工程公司、设计院 → 竞争对手；施工、安装、建工、市政、送变电这类资源方 → 合作生态（补施工资源与当地关系）
    • 
        
  • 入选门槛：库内中标 ≥2 次，或所在项目体量 ≥1 亿元；纯运营/运维/购买服务类项目不参与挖掘（承接方不是工程承包主体）
    • 
        
  • 联合体项目金额按参与家数分摊计入各单位，避免多家都挂同一个全额导致虚高；卡片里的业绩可点开原文复核
    • 
        
  • 挖掘结果按名称自动去重，已在库里的只补充业绩、不重复收录，所以每周只会新增真正没见过的单位
    • 
        
  • 动态自动刷新：已入库的单位（含 A/B 建议清单 17 家）每周更新时会自动把库内新中标追加进「近期业绩」，按日期倒序最多保留 5 条——单位档案不用手工维护，新中标会自己长出来
    • 
        
  • 深度档案补厚：脚本每周自动列出档案正文不足 60 字的单位，生成 raw/_inbox/thin_queue.json；每周任务会从中挑 4-6 家做深度调研（资质等级、在手订单、撞单点、相对优劣势）并覆盖写回。存量薄档案会被逐周消化完，新出现的单位也会在下一周自动获得深度档案——这是全流程里唯一需要联网检索的环节，其余都是脚本自动完成
    •
